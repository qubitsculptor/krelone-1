# Krelone

Agrivoltaic (AgriPV) land-value optimization platform.

Motors maximize energy. **Krelone decides why the panels should move** — to maximize the total value of the land (crop + energy).

## Docs

- [PROJECT_BRIEF.md](./PROJECT_BRIEF.md) — product objective and build status

## Local development

```bash
npm install
npm install -g base44@latest
base44 dev
```

Or frontend-only against the hosted backend:

```bash
npm run dev
```

See Base44 docs for env setup (`.env.local`).
